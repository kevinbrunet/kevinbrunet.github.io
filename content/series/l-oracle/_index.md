Cette série montre comment un oracle transforme la génération en boucle de recherche, puis permet de router les échecs vers les modèles dont les angles morts sont réellement complémentaires.

Le premier article étudie la valeur des tentatives vérifiées. Le second montre pourquoi le meilleur modèle d'un classement n'est pas forcément celui qui complète le mieux le précédent.
